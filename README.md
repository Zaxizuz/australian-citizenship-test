# Australian Citizenship Test — 333 Practice Questions

An offline-friendly, single-file study app covering 333 practice questions for the
Australian citizenship test, with study, flashcard and quiz modes.

**▶ Live site: https://zaxizuz.github.io/australian-citizenship-test/**

## Contents

| File | What it is |
| --- | --- |
| `australian-citizenship-test-333-questions.html` | The study app — one self-contained file (inline CSS + JS, no dependencies). Works offline; just open it in a browser. |
| `australian-citizenship-test-333-questions.json` | The same question bank as structured data, for reuse elsewhere. |
| `index.html` | Redirect so the site root loads the app. |

## Sharing it

Send people the live link above, or download the single HTML file and open it —
it needs no server, no build step and no internet connection.

## Source & disclaimer

Questions were compiled from a publicly available study video and cross-checked
against the official *Our Common Bond* resource:
<https://immi.homeaffairs.gov.au/citizenship/become-a-citizen/before-you-apply/our-common-bond>

This is an unofficial study aid and is not affiliated with or endorsed by the
Australian Government. Always confirm against the official materials.
